3. Datos Personales Recogidos

Hostal Prada puede recopilar los siguientes tipos de datos personales:

  • Datos de identificación: nombre, apellidos.
  • Datos de contacto: dirección de correo electrónico, número de teléfono.
  • Datos de reserva: información sobre la estancia, preferencias de habitación, fechas de llegada y salida.
  • Datos de pago: información de la tarjeta de crédito u otros métodos de pago (tratados a través de pasarelas de pago seguras).
  • Datos de navegación: dirección IP, tipo de dispositivo, páginas visitadas en el Sitio Web, tiempo de navegación, etc.

4. Finalidades del Tratamiento

Los datos personales que proporcionas serán tratados con las siguientes finalidades:

  • Gestión de reservas: procesar y gestionar tus reservas de alojamiento.
  • Comunicación: enviarte confirmaciones de reserva, información relevante sobre tu estancia o responder a tus consultas.
  • Facturación: emitir y enviar facturas o comprobantes de pago.
  • Mejora de servicios: analizar datos de navegación para mejorar nuestros servicios y la experiencia de usuario en el Sitio Web.

5. Conservación de los Datos

Los datos personales se conservarán durante el tiempo necesario para cumplir con las finalidades para las cuales fueron recopilados y para cumplir con nuestras obligaciones legales, fiscales y contables. Una vez cumplidas estas finalidades, los datos serán eliminados o anonimizados.

6. Comunicación de Datos a Terceros

Hostal Prada no compartirá tus datos personales con terceros, excepto en los siguientes casos:

  • Obligación legal: para cumplir con obligaciones legales, como solicitudes de autoridades públicas o policiales.
